# Risk assessment

For the current plan, list:

- **Unknowns** — things we have not verified. For each, the cheapest way to verify.
- **Assumptions** — what the plan takes for granted.
- **Risks** — what could go wrong, likelihood (low/med/high), and mitigation.
- **Irreversible steps** — anything destructive or outward-facing that needs
  confirmation first.

End with the one unknown that should be resolved first.
