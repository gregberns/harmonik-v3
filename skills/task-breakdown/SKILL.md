# Task breakdown

1. Restate the goal in one sentence and list explicit constraints.
2. Split the work into tasks that each produce one verifiable result
   (a passing test, a working command, a written file).
3. Order tasks by dependency; mark tasks that can run in parallel.
4. For each task give: title, files likely touched, done-when criterion.
5. Flag any task that is too large to finish in one session and split it.

Output a numbered list. Do not start implementing.
