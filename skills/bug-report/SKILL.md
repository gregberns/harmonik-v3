---

# Bug report

```markdown
## <short title>
**Expected:** <what should happen>
**Actual:** <what happened, with exact error text>
**Repro:**
1. <minimal steps>
**Environment:** <versions, OS, config that matters>
**Notes:** <suspected cause only if verified>
```

Reproduce it once more before reporting. Keep the repro minimal.
